## ✨ Visão geral

Este projeto foi pensado para funcionar como um site institucional de uma academia, com foco em:

- apelo visual forte e profissional;
- navegação simples e intuitiva;
- layout responsivo para desktop, tablet e mobile;
- apresentação de planos, benefícios e profissionais;
- CTA para conversão de leads e contato.

---

## 🏋️‍♂️ Features

- Layout moderno e elegante em Bootstrap
- Seções de destaque para hero, sobre, planos e depoimentos
- Cards para serviços e benefícios
- Área de professores/trainers
- Formulário de contato
- Design responsivo
- Estrutura simples para fácil customização

---

## 🛠️ Tecnologias utilizadas

## ▶️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/diegoorodrigues006/projeto-fitness-bootstrap.git
cd projeto-fitness-bootstrap
```

2. Abra o arquivo `index.html` diretamente no navegador ou utilize um servidor local.

Exemplo com Python:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
